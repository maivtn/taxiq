# Nexora OneQR — Business User Flows V2

## 1. Owner creates a Business Workspace
Create Workspace → Business → Select industry → Select goals → AI recommendation → Review modules/roles/approval → Save Draft → Preview → Publish → Download QR.

## 2. Individual creates a Personal Workspace
Create Workspace → Personal → Select profession → Select goals → AI creates digital profile template → Review → Publish personal OneQR.

## 3. Association creates Member Portal
Create Workspace → Organization → Association → Select membership/events/donation/voting → AI proposal → Configure chapters and roles → Publish.

## 4. Government creates Public Service QR
Create Workspace → Government → Select level/department → Select citizen services → Configure public/private content → Approval hierarchy → Publish public service QR.

## 5. New visitor scan
Scan → Public landing → Select public module OR protected module → OTP if required → Complete action → Confirmation.

## 6. Returning customer scan
Scan → Recognized session → Personalized home → Continue pending task or choose module → Complete → Notification / next action.

## 7. Staff requests discount
Scan same QR → Staff portal → Open transaction → Request discount → Approval created → Owner notified → Approve/Deny → Staff receives result → Continue.

## 8. Owner updates Master QR
Open Builder → Change inherited setting → Impact preview → Save → Only inherited Child QR updated → History recorded.
