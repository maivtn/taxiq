# Nexora OneQR — UI Screen Specification V2

## A. Phía Owner / Admin

### A01. Workspace Selector
**Mục tiêu:** Chọn tư cách đang làm việc.  
**Thành phần:** Avatar, workspace cards, role badge, create workspace.  
**Hành động:** Open workspace, switch role, create new workspace.

### A02. Create Workspace
**Mục tiêu:** Bắt đầu onboarding.  
**Thành phần:** Personal, Business, Organization, Government, AI guide.  
**Hành động:** Chọn loại workspace.

### A03. AI Setup — Industry / Type
**Mục tiêu:** Chọn ngành hoặc loại hình.  
**Hành động:** Chọn một template phù hợp hoặc nhập mô tả riêng.

### A04. AI Setup — Goals
**Mục tiêu:** Xác định nhu cầu.  
**Thành phần:** Check-in, booking, payment, membership, staff, documents, approvals, public services.

### A05. AI Recommendation Review
**Mục tiêu:** Review cấu hình AI đề xuất.  
**Hiển thị:** Master QR, child QR, modules, roles, approval rules.  
**Hành động:** Accept all, customize, save draft.

### A06. Dashboard
**Mục tiêu:** Tổng quan vận hành.  
**KPI:** Scans, active QR, self-service rate, pending approvals.  
**Hành động:** Open builder, approval inbox, analytics.

### A07. OneQR Builder
**Mục tiêu:** Cấu hình nội dung và module.  
**Bố cục:** Module list, settings panel, live mobile preview.  
**Hành động:** Drag, enable, disable, customize, preview by role.

### A08. Master & Child QR
**Mục tiêu:** Quản lý hệ thống QR.  
**Hiển thị:** Master QR, child hierarchy, inherited/customized/disabled.  
**Hành động:** Add child, duplicate, archive, print.

### A09. Roles & Permissions
**Mục tiêu:** Quy định ai được làm gì.  
**Thành phần:** Roles, permission profiles, scope, context restrictions.  
**Hành động:** Assign, clone, override, revoke.

### A10. Approval Rules
**Mục tiêu:** Cấu hình hành động cần duyệt.  
**Thành phần:** Trigger, amount limit, approver, backup approver, expiration.

### A11. Approval Inbox
**Mục tiêu:** Xử lý yêu cầu vượt quyền.  
**Hành động:** Approve, deny, request information, one-time approval.

### A12. Notifications
**Mục tiêu:** Quản lý thông báo.  
**Kênh:** App, email, SMS, AI Voice.  
**Hành động:** Mark read, open request, configure channel.

### A13. Activity History
**Mục tiêu:** Minh bạch hoạt động.  
**Hiển thị:** Actor, action, object, time, result, approver.

### A14. Publish / Print / Share
**Mục tiêu:** Đưa QR vào sử dụng.  
**Hành động:** Publish, download PNG/SVG/PDF, copy link, print size presets.

## B. Phía Visitor / Customer

### B01. Scan Landing
**Mục tiêu:** Mở nhanh, không ép đăng nhập.  
**Hiển thị:** Brand, public modules, primary action, view all.

### B02. OTP Identity
**Mục tiêu:** Xác thực tối thiểu khi cần.  
**Hành động:** Phone/email, OTP, continue as guest when allowed.

### B03. Personalized Home
**Mục tiêu:** Hiển thị hành động phù hợp.  
**Ví dụ:** Continue checkout, upcoming booking, reward balance, pending approval.

### B04. View All Modules
**Mục tiêu:** Cho người dùng chủ động mở mọi module được phép.

### B05. Check-in
**Mục tiêu:** Tự check-in bằng điện thoại.  
**Bước:** Confirm identity, select appointment/walk-in, select service, submit.

### B06. Booking
**Mục tiêu:** Đặt lịch.  
**Bước:** Service, location, staff preference, date/time, confirmation.

### B07. Payment & Tip
**Mục tiêu:** Chọn phương thức được chủ sở hữu bật.  
**Ghi chú:** Hành động nhạy cảm có thể cần xác thực bổ sung.

### B08. Rewards & Membership
**Mục tiêu:** Xem điểm, quyền lợi, coupon, membership status.

### B09. Review
**Mục tiêu:** Thu thập phản hồi và dẫn đến kênh review được cấu hình.

### B10. Staff Portal
**Mục tiêu:** Cùng QR nhưng hiển thị giao diện nhân viên.  
**Hành động:** Clock-in, turn, receive customer, complete service, request approval.

### B11. Approval Request Status
**Mục tiêu:** Theo dõi yêu cầu.  
**Trạng thái:** Pending, needs info, approved, denied, expired.

### B12. Limited Access
**Mục tiêu:** Giải thích an toàn khi quyền bị giới hạn.  
**Hành động:** Verify, request access, return home.

### B13. Success Confirmation
**Mục tiêu:** Xác nhận hành động thành công và gợi ý bước tiếp theo.
